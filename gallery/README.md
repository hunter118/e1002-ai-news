# E1002 相册

这个文件夹就是相册管理后台，不再依赖外部网站。

## 上传照片

1. 打开 [`photos`](./photos) 文件夹。
2. 点击 **Add file → Upload files**。
3. 拖入 JPG、PNG 或 WebP 文件，然后点击 **Commit changes**。
4. GitHub Actions 会立即将照片居中裁切为 800×480、转换为 Spectra 6 六色格式，并发布到 `gallery` 分支。设备在下次每小时检查或重新上电时下载新相册。

最多支持 20 张照片。按照文件名自然排序；建议使用 `01_名称.jpg`、`02_名称.jpg` 控制播放顺序。要删除照片，打开对应文件后点击删除按钮并提交。

注意：仓库是公开的，主动上传到这里的 JPG、PNG 或 WebP 会公开显示。迁移时保留的 `.epd` 是设备格式，只用于延续原有画面。

## 自动翻页

编辑 [`config.json`](./config.json) 中的 `interval_seconds`：

- `0`：永远不自动翻页；
- `600`：每 10 分钟；
- `1800`：每 30 分钟；
- `3600`：每 60 分钟。

允许范围为 10～86400 秒，或使用 0 关闭。考虑到彩色电子纸的耗电和刷新寿命，建议使用 600 秒以上。
